# Free-TV Player — production build

A production-quality web app and hardened data pipeline built **on top of** two upstream
community playlist repositories — without changing a single byte of their working outputs:

| Upstream | Role in this project |
|---|---|
| [Free-TV/IPTV](https://github.com/Free-TV/IPTV) | Curated, human-maintained markdown channel lists — **2,080 channels across 97 lists** (87 countries + 8 themed categories + 2 VOD lists) — plus its playlist generator, stream health checker, status-dashboard generator and 7 CI workflows. |
| [iptv-org/iptv → `streams/`](https://github.com/iptv-org/iptv/tree/master/streams) | **326 per-country M3U files with 17,968 channel entries** across 202 territory codes (incl. 124 provider files such as Pluto TV, Samsung TV Plus, Stingray). Vendored under [`sources/iptv-org/streams/`](sources/iptv-org/streams/). |

Merged catalog: **20,048 channel entries · 182 countries · 8 categories**, regenerated by one
deterministic script and served as a zero-dependency static web app.

## Repo audit — what the upstreams actually contain

Neither upstream is a web app, so "existing pages, components, CSS, artwork" maps to this:

| Asset | Free-TV/IPTV | iptv-org/iptv (streams) |
|---|---|---|
| Pages | `README.md` (flag-grid landing page, Ⓖ/Ⓢ/Ⓨ legend) + GitHub Pages status dashboard generated into `docs/index.html` by `generate_dashboard.py` | README + per-country stream files only |
| Components | `make_playlist.py` (md → M3U), `check_channels.py` (6-state stream prober with ffprobe double-check), `generate_dashboard.py` (history.jsonl → static HTML) | none (pure data) |

| CSS / artwork | CSS is baked inside `generate_dashboard.py`'s output (state colors `--s-alive…--s-dead`); artwork = channel logos + [circle-flags](https://github.com/hatscripts/circle-flags) country flags | logos referenced via `tvg-logo` |
| Working features | ✅ verified: `python3 make_playlist.py` regenerates **byte-identical** playlists (`REGEN_IDENTICAL`); dashboard generator runs clean over the 74 MB checker history (282,165 check rows) | ✅ well-formed M3U parses cleanly |
| Missing | ❌ no LICENSE file, ❌ typo in workflow job id (`update-plalist`), ❌ no web UI to browse/play | ❌ no grouped UI, ❌ no dedup across files |

## What was preserved (nothing broken)

- **`make_playlist.py` runs unchanged** in this repo against the untouched `lists/` and produces
  playlists **byte-identical** to upstream (verified by `diff`; CI re-verifies on every push).
- **`check_channels.py`, `generate_dashboard.py`, `epglist.txt`, `flag_order.txt`, the checker
  history and all 7 upstream workflows** are carried over as-is.
- **All original metadata survives the merge**: `tvg-id`, `tvg-name`, `tvg-logo`, `tvg-chno`,
  `tvg-country`, `group-title`, EPG ids, Ⓖ/Ⓢ/Ⓨ markers (parsed into searchable tags), quality
  suffixes like `(720p)`.
- **Artwork preserved**: original channel logos, circle-flags country flags (same CDN the Free-TV
  README uses), and the dashboard's state-color vocabulary reused in the app's badge system.
- **Upstream README** kept verbatim at [`docs/upstream-free-tv-readme.md`](docs/upstream-free-tv-readme.md).

## What was added

```
┌──────────────────────────── scripts/build_catalog.py ────────────────────────────┐
│  lists/*.md (Free-TV)      +      sources/iptv-org/streams/*.m3u                 │
└──────────────┬──────────────────────────────────┬───────────────────────────────┘
               ▼                                  ▼
   make_playlist.py (unchanged)      app/data/catalog.js + channels-<key>.js
   → playlist.m3u8 + playlists/      (JS modules, lazy-loaded per view)
               │                                  │
               ▼                                  ▼
        GitHub Actions CI              app/ (vanilla SPA)  ──build_bundle.py──▶ dist/index.html
```

- **Web app** (`app/`) — vanilla JS/CSS, no framework, no runtime dependencies except vendored
  hls.js: hash-routed home/country/category/search views, global search across all 20k+ entries,
  in-list filter + group chips, hls.js player modal with graceful fallbacks (YouTube/Twitch links
  open on the provider, MPEG-DASH shows copy-out instructions, errors explain geo-blocking),
  deterministic SVG initials artwork when a logo is missing, dark/light theme, responsive
  layout, keyboard shortcuts (`/` search, `Esc` close), lazy per-country data loading.
- **`scripts/build_catalog.py`** — deterministic md+M3U → JS catalog builder (dedup, uk→GB code
  normalization, provider labels for `_pluto`/`_samsung`/… files).
- **`scripts/build_bundle.py`** — single-file `dist/index.html` build (works offline / `file://`).
- **Embedded AI Studio app** (`#/app`, sidebar "Web app") — renders the companion app ([ai.studio](https://ai.studio/apps/5d188f2a-5162-4288-a32e-990a76df807a)) in an iframe panel with an "Open app" launch-card fallback for when Google blocks framing or requires sign-in.
- **Vercel-ready** — `vercel.json` pins `framework: null` (Other/static preset) and serves `app/` as the static output, so Vercel does not auto-detect the Python tooling and look for a Python entrypoint.
- **CI** (`.github/workflows/ci.yml`) — ruff lint, "playlists must be current" gate, catalog +
  bundle build, artifact upload, GitHub Pages deploy job. All upstream workflows kept.
- **`Makefile`**, **`pyproject.toml`** (ruff config), **MIT `LICENSE`**, refreshed `README`,
  legal disclaimer in app footer.

## Quickstart

```bash
make playlist   # regenerate M3U playlists from lists/ (byte-identical to upstream)
make catalog    # rebuild app/data/*.js from lists/ + sources/iptv-org/streams/
make bundle     # single-file dist/index.html
make check      # ruff lint the new tooling
make serve      # http://localhost:8000  (serve app/ or open dist/index.html directly)
```

## Data sources & refresh

- Free-TV lists are the working originals in [`lists/`](lists/).
- iptv-org streams are vendored in [`sources/iptv-org/streams/`](sources/iptv-org/streams/)
  (snapshot 2026-10-13). Refresh:
  `git clone --depth 1 https://github.com/iptv-org/iptv /tmp/iptv-org && cp /tmp/iptv-org/streams/*.m3u sources/iptv-org/streams/ && make catalog`

## Legal

This project **does not host, proxy or re-distribute any video stream**. It indexes
metadata (names, logos, EPG ids) and links to publicly listed stream URLs published by the two
upstream community repos; playback happens directly from the broadcaster's own servers.
Channels may be geo-restricted, offline, or removed at any time, and availability is not
guaranteed. Rights holders who want a channel delisted should open an issue in the
corresponding upstream repository.
